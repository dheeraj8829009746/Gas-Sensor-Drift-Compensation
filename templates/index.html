EXPLAINED

What is sensor drift?

Sensors age, are poisoned, and react to temperature and humidity. The same gas therefore produces a slightly different 128-value signature every month. Because the classifier only ever saw Batch 1, it gradually fails on Batches 2-10.

Compensation removes the batch-specific shift by aligning every batch to the reference batch before the model sees the data, using only unlabelled samples from the new batch.

SENSOR DRIFT DETECTION

Measuring Drift

Each batch is compared with Batch 1 (the reference) using four complementary measures.

Mean shift

Average distance between batch mean and Batch 1 mean, in Batch 1 standard deviations.

Variance shift

Average |log(variance ratio)|. Zero means the same spread.

Distribution shift

Kolmogorov-Smirnov statistic per sensor, averaged. 0 = same distribution, 1 = disjoint.

Drift score

KS computed separately for each gas, so a change in gas mixture is not mistaken for sensor drift.

DRIFT COMPENSATION

Reference-Batch Correction

Every batch is mapped towards Batch 1 before classification. Only unlabelled samples of the batch are needed to estimate the correction.

1. Batch-wise Standardization

Each batch is z-scored with its own mean and standard deviation, removing batch offset and scale.

2. Reference Mean Alignment

x' = x - mean(batch) + mean(Batch 1). Corrects the baseline shift only.

3. Reference CORAL

Matches mean and covariance of the batch to Batch 1 (correlation alignment), also fixing sensor-to-sensor relationships.

PROJECT INFORMATION

About the Project

OBJECTIVE

Drift-robust gas classification

Classify six gases from a 16-sensor array (128 features) and keep accuracy high as the sensors drift over 36 months.

DATASET

UCI Gas Sensor Array Drift

13,910 measurements in 10 batches. Batch 1 is the reference; Batches 2-10 carry increasing drift.

METHOD

Train once, compensate each batch

Models are trained only on Batch 1. Each new batch is aligned to Batch 1 with unlabelled statistics, then classified by the unchanged model.

LIMITATIONS

Read results carefully

Compensation needs a pool of unlabelled samples from each new batch, so single readings must name their batch. The best technique is chosen on the same batches it is reported on, so treat gains as optimistic until checked on new batches.
